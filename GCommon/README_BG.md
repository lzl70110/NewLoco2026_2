# 📘 Описание на проекта
„Локо“ е ASP.NET Core MVC уеб приложение за управление на локомотиви, записи за гориво и работни смени, които записват начални и крайни показания (Km/Mh) и автоматично изчисляват изминатите километри или моточасове за деня.

Проектът е разработен за **изпита по ASP.NET Fundamentals в SoftUni** и демонстрира коректна MVC архитектура, автентикация с Identity, CRUD операции и ясно структурирана логика, готова за бъдещо разширяване.

В момента приложението е **само на английски език**. Локализация (bg-BG) е планирана като бъдеща стъпка.

---

# 🎯 Основни функционалности
- **Модул „Локомотиви“** — пълен CRUD (има Admin Area, но без ролеви ограничения)
- **Модул „Гориво“** — създаване, редакция, изтриване, списък + Fuel Report
- **Модул „Работни смени“** — начало/край на Km/Mh и автоматично изчисление
- **Публичен списък на локомотиви** за всички гости
- **Пълен достъп** за всички вписани потребители
- **Login / Register (Identity)** — без роли
- Допълнителни инструменти: **Калкулатор**, **Календар**

# 🔐 Автентикация и достъп
Приложението използва ASP.NET Core Identity.

### Невписани потребители:
- Виждат само **публичния списък с локомотиви**

### Вписани потребители:
- Имат достъп **до всички функционалности в системата** (за момента)
- Ролеви права **все още не са внедрени**

# 🚀 Инсталация
1. Клонирайте репозиторито:
```bash
git clone https://github.com/lzl70110/NewLoco2026_2
```
2. Влезте в директорията:
```bash
cd NewLoco2026_2
```
3. Уверете се, че SQL Server работи.
4. Прилагате миграциите:
```bash
dotnet ef database update
```
5. Стартирате приложението:
```bash
dotnet run --project NewLoco.Web
```
